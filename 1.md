# Step 1: Database Setup, Drizzle Schema & Seed Script

## Objective
Configure Neon PostgreSQL with Drizzle ORM, establish a normalized database schema, and write a database seed script for the 3 tiers and 9 questions.

## Detailed Tasks

### 1. Install Dependencies & Drizzle Setup
- Install required packages:
  - `drizzle-orm`
  - `@neondatabase/serverless`
  - `dotenv`
  - `drizzle-kit` (dev dependency)
- Create `drizzle.config.ts` targeting PostgreSQL with schema location `./db/schema.ts`.
- Create `db/index.ts` initializing the Neon serverless HTTP / pool driver with Drizzle ORM.

### 2. Database Schema (`db/schema.ts`)
Define the following Drizzle PostgreSQL tables:

1. **`teams`**:
   - `id`: `uuid` / `serial` (Primary Key)
   - `authUserId`: `varchar` (Unique, linked to Neon Auth user ID)
   - `teamName`: `varchar` (Not Null)
   - `teamLeaderName`: `varchar` (Not Null)
   - `balance`: `integer` (Default 0, Not Null)
   - `createdAt`: `timestamp` (Default `now()`)
   - `updatedAt`: `timestamp` (Default `now()`)

2. **`tiers`**:
   - `id`: `uuid` / `serial` (Primary Key)
   - `tierNumber`: `integer` (Unique, 1, 2, or 3)
   - `name`: `varchar` (Not Null, e.g. "Tier 1", "Tier 2", "Tier 3")
   - `description`: `varchar` (Not Null)
   - `createdAt`: `timestamp` (Default `now()`)

3. **`questions`**:
   - `id`: `uuid` / `serial` (Primary Key)
   - `tierId`: `integer` / `uuid` (Foreign Key referencing `tiers.id`)
   - `question`: `text` (Not Null)
   - `answer`: `text` (Not Null - **Server-only**, never selected or returned to client)
   - `reward`: `integer` (Not Null)
   - `createdAt`: `timestamp` (Default `now()`)

4. **`team_tiers`**:
   - `id`: `uuid` / `serial` (Primary Key)
   - `teamId`: `integer` / `uuid` (Foreign Key referencing `teams.id`)
   - `tierId`: `integer` / `uuid` (Foreign Key referencing `tiers.id`)
   - `status`: `varchar` (Enum: `'LOCKED'`, `'UNLOCKED'`, `'COMPLETED'`, `'FAILED'`)
   - `retriesRemaining`: `integer` (Default 2)
   - `completedAt`: `timestamp` (Nullable)
   - `createdAt`: `timestamp` (Default `now()`)
   - `updatedAt`: `timestamp` (Default `now()`)
   - **Constraint**: Unique index on `(teamId, tierId)`

5. **`question_attempts`**:
   - `id`: `uuid` / `serial` (Primary Key)
   - `teamId`: `integer` / `uuid` (Foreign Key referencing `teams.id`)
   - `questionId`: `integer` / `uuid` (Foreign Key referencing `questions.id`)
   - `tierId`: `integer` / `uuid` (Foreign Key referencing `tiers.id`)
   - `submittedAnswer`: `text` (Not Null)
   - `isCorrect`: `boolean` (Not Null)
   - `attemptedAt`: `timestamp` (Default `now()`)

6. **`team_question_rewards`**:
   - `id`: `uuid` / `serial` (Primary Key)
   - `teamId`: `integer` / `uuid` (Foreign Key referencing `teams.id`)
   - `questionId`: `integer` / `uuid` (Foreign Key referencing `questions.id`)
   - `rewardAmount`: `integer` (Not Null)
   - `grantedAt`: `timestamp` (Default `now()`)
   - **Constraint**: Unique index on `(teamId, questionId)` to prevent duplicate reward payouts under concurrency.

### 3. Database Seed Script (`db/seed.ts`)
- Script to populate:
  - 3 Tiers:
    - Tier 1 (Novice Tier)
    - Tier 2 (Pro Tier)
    - Tier 3 (Master Tier)
  - 9 Mock Questions (3 questions per tier):
    - Tier 1: Question 1 ($100), Question 2 ($150), Question 3 ($200)
    - Tier 2: Question 1 ($250), Question 2 ($300), Question 3 ($350)
    - Tier 3: Question 1 ($500), Question 2 ($600), Question 3 ($750)
- Ensure correct answers exist ONLY in database records.

- [ ] Drizzle ORM and Neon Postgres driver configured cleanly.
- [ ] Schema exported and compile-checked without TypeScript errors.
- [ ] Seed script executes successfully creating 3 tiers and 9 questions.
