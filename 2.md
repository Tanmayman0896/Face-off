# Step 2: Authentication & Team Onboarding Flow

## Objective
Implement Neon Auth authentication and team onboarding, collecting Team Name and Team Leader Name, associating them with the authenticated server session in PostgreSQL, and protecting authenticated routes.

## Detailed Tasks

### 1. Neon Auth Configuration (`lib/auth.ts`)
- Integrate `@neondatabase/auth` or Neon Auth SDK / server session helpers.
- Implement server-side session helper `getAuthSession()`:
  - Retrieves authenticated `authUserId` directly from server-side session.
  - Returns `null` if unauthenticated.
- Implement helper `getCurrentTeam()`:
  - Retrieves authenticated user session from `getAuthSession()`.
  - Queries `teams` table in DB by `authUserId`.
  - Returns team record or `null` if onboarding incomplete.

### 2. Onboarding / Landing Page (`app/page.tsx`)
- Unauthenticated view:
  - Neon Auth sign-in / sign-up component or redirect.
  - Modern aesthetic landing page explaining the game rules.
- Authenticated but non-onboarded view:
  - Onboarding form collecting:
    - **Team Name** (`teamName`)
    - **Team Leader Name** (`teamLeaderName`)
  - Server Action `completeOnboarding`:
    - Validates server session.
    - Inserts new team row into `teams` table.
    - Automatically creates initial `team_tiers` entry for Tier 1 with status `'UNLOCKED'` and `retriesRemaining: 2`.
    - Creates `team_tiers` entries for Tier 2 and Tier 3 with status `'LOCKED'`.
    - Redirects user to `/dashboard`.
- Authenticated and onboarded view:
  - Auto-redirects directly to `/dashboard`.

### 3. Server Authorization & Route Protection
- Route guards to prevent unauthenticated access.
- Prevent spoofing by rejecting any `teamId` passed from client; always derive `teamId` from authenticated server session.

## Acceptance Criteria
- [ ] Authentication state is persisted across browser refreshes and restarts.
- [ ] Users cannot access `/dashboard` without completing authentication and onboarding.
- [ ] Onboarding creates team in DB and unlocks Tier 1 for the team.
- [ ] `authUserId` securely maps session to database team record.
