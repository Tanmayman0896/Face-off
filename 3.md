# Step 3: Main Dashboard & Tier System UI

## Objective
Build the main game dashboard displaying the team header, digital currency balance, and 3 tier cards driven entirely by PostgreSQL database state.

## Detailed Tasks

### 1. Dashboard Data Fetching (`lib/queries.ts`)
- Server function `getDashboardData()`:
  - Validates authenticated server session.
  - Queries `teams` for team name, leader name, and balance.
  - Queries `team_tiers` joined with `tiers` for all 3 tiers.
  - For each tier, calculates solved questions count (`X / 3`) from `question_attempts` or `team_question_rewards`.
  - Determines exact DB state (`UNLOCKED`, `LOCKED`, `COMPLETED`, `FAILED`).

### 2. Dashboard Layout & Design (`app/dashboard/page.tsx`)
- **Header Component**:
  - Displays **Team Name** and **Team Leader Name**.
  - Displays **Digital Money Balance** (e.g. `🪙 $450 Game Credits`), visually distinct from real currency.
- **3 Tier Cards Grid**:
  - **Tier 1 Card**:
    - Title: Tier 1 - Start Tier
    - Questions: `3`
    - Remaining Retries: `X / 2`
    - Potential Reward: `$450`
    - Solved Progress: `X / 3`
    - Status Badge: `UNLOCKED` / `COMPLETED` / `FAILED`
    - Action Button: `[ Continue ]` or `[ Start Tier ]` or `[ Completed ]` or `[ Failed ]`
  - **Tier 2 Card**:
    - Status Badge: `LOCKED` (until Tier 1 completed)
    - Unlock requirement notice: `🔒 Complete Tier 1`
    - Action Button: `[ Locked ]` (disabled when locked)
  - **Tier 3 Card**:
    - Status Badge: `LOCKED` (until Tier 2 completed)
    - Unlock requirement notice: `🔒 Complete Tier 2`
    - Action Button: `[ Locked ]` (disabled when locked)

### 3. Server-Side Access Control
- Server Component check on `/dashboard` ensuring user is authenticated and onboarded.
- Tier card action buttons navigate to `/tier/[tierId]`.

## Acceptance Criteria
- [ ] Tier statuses (`UNLOCKED`, `LOCKED`, `COMPLETED`, `FAILED`) are determined strictly from DB queries.
- [ ] User cannot unlock Tier 2 without solving all 3 questions in Tier 1.
- [ ] User cannot unlock Tier 3 without solving all 3 questions in Tier 2.
- [ ] Header displays correct team name, leader, and digital currency balance.
